# DeathMore

**DeathMore** is a Minecraft Forge 1.12.2 mod that transforms death into the beginning of a new path.

Instead of simply respawning, players may face judgment, accumulate karma, choose supernatural races, make irreversible decisions, and become part of a world where souls, contracts, relics, and consequences shape every playthrough.

## Current Features

* Karma system (-250 to +250)
* Limbo dialogue system
* Multiple supernatural races
* Permanent death support
* Holy items and blessed blocks
* Possession mechanics
* Vampire territory system
* Ghost body persistence
* Contract system with the Contractor

## Planned Features

* Relics and legendary enchantments
* Bestiary / lore book
* Rituals and supernatural events
* Expanded multiplayer interactions
* Additional dimensions and structures

## Development Status

This project is currently in **pre-alpha planning**. Most systems are being designed before implementation.

## Target Version

* Minecraft Forge **1.12.2**
